# Security and confidentiality

Do not commit:

- passwords, API keys, OAuth tokens or private configuration;
- PFS, POF, credit reports, bank statements or personal identifiers;
- patient/client records or protected health information;
- nonpublic contracts unless the repository is explicitly controlled for them;
- unredacted lender, legal or employment records.

Use the restricted Drive data room for sensitive material. Public or broadly
shared systems store only approved summaries and source links with appropriate
access.
