# Repository agent instructions

Before modifying public VYTAL content, read:

1. `README.md`
2. `governance/STATUS_AND_DECISIONS.md`
3. `governance/AGENTS_AND_SKILLS.md`
4. The relevant public project prompt in `prompts/`

spelling VYTAL. Treat the flagship program as proposed/pre-development,
Pouches as R&D and Innovation as concept/diligence unless approved sources
change the stage. Do not commit restricted data. Update affected documentation
together.
